# CNTP
A library for generating and processing point clouds from the timelapse photogrammetry.


## Installation
```
$ git clone git@github.com:MohammadUmayr/CNTP_hackathon.git
$ cd ./CNTP_hackathon
$ conda env create -f environment.yml
$ conda activate cntp
$ pip install -e .
```
